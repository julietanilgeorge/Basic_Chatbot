# 🤖 Basic Rule-Based Chatbot

A beginner-friendly chatbot developed using Python.

## 📌 About the Project

This chatbot accepts messages from the user and responds according to predefined rules. It demonstrates how basic Python logic can be used to create a simple interactive conversation.

## ✨ Features

- Recognizes five predefined messages.
- Provides predefined responses.
- Accepts user input.
- Handles unrecognized messages if a fallback response is implemented.

## 🛠️ Technologies Used

- Python

## ▶️ How to Run

1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python chatbot.py
```

## 🎯 Learning Outcomes

This project helped me practise Python input and output, conditional statements, string comparisons, and rule-based decision-making.
